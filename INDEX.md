## ⚡ Guia Rápido por Tarefa

### Abrir Projeto
```
→ Duplo clique em index.html
→ F12 > Abrir DevTools
```

### Preencher Formulário
```
→ Clique "Começar grátis"
→ Preencha 9 etapas
→ Veja "Seu formulário foi recebido"
```

### Ver Dados
```
→ F12 > Console
→ localStorage.getItem('meuTreinoFormData')
```

### Customizar Cores
```
→ Abra css/style.css
→ Edite --primary (linha 17)
→ Save (Ctrl+S)
```

### Configurar Backend
```
→ Abra config.js
→ Edite BASE_URL (linha 12)
→ Implemente /api/v1/auth/register
```

### Testar Mobile
```
→ Abra index.html
→ F12 > Ctrl+Shift+M
→ Teste responsividade
```

### Deploy
```
→ Hospede em: Vercel, Netlify, GitHub Pages
→ Aponte domínio
→ Pronto!
```
